# NEO

Currently, I am still figuring out how to full swap from arduino IDE to ESP-IDF on VSCode.

This project will have full functionality once I learn the basics of ESP-IDF in VSCode. The functions will include:
  - 24v RGB LED strips controlled by MOSFETs
  - 24v Piezo Buzzer controlled by MOSFET (up to 95dB)
  - ILI9341 LCD Screen
  - Various lever switches for configurations
  - Big red button
  - RC522 RFID reader
  - 4x4 keypad
  - Servo (future addition)
